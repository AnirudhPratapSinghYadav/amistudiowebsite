# Third-party code and assets

No third-party scripts, embeds, fonts or trackers load at runtime. Everything is bundled and served
from the site's own origin, which is what lets the CSP stay at `'self'` only.

## Runtime packages (bundled)

| Package | Why |
|---|---|
| react, react-dom | UI |
| react-router-dom | Client routing for 9 pages plus the 404 |
| framer-motion | Reveals, page transition, route wipe, scroll effects. Respects reduced motion via `MotionConfig reducedMotion="user"` |
| @fontsource-variable/montserrat, @fontsource-variable/inter, @fontsource/permanent-marker | Self-hosted fonts (SIL Open Font License) |

Versions are pinned exactly in `package.json`, and the lockfile is committed.

## Dev and build only (not shipped)

| Tool | Why |
|---|---|
| vite, @vitejs/plugin-react | Build and dev server |
| simple-icons | Source for the platform icons in `src/components/brandIcons.js`, generated by `scripts/brand_icons.mjs` (CC0 1.0) |
| Python Pillow, ffmpeg | `scripts/build_media.py`: resizes photos, encodes the beats and previews, draws waveforms, renders the share image |
| Montserrat TTF files in `assets/reference/fonts/` | Used only by `build_media.py` to draw the wordmark into `og-image.jpg` and the stacked logo PNGs (SIL Open Font License, `OFL.txt` included) |

## Media from the client's own releases

| What | Source | Note |
|---|---|---|
| 30-second release previews (`public/audio/*-preview.mp3`) | Spotify preview clips of his own songs (`previewSrc` in `releases.json`, fetched by `scripts/fetch_releases.py`) | Stored on the site so nothing loads from Spotify. Confirm with the client (see `docs/client-needs.md`) |
| Cover art (`public/releases/`) | His Spotify releases | Same |
| Music video stills (`public/releases/*-video-*.webp`) | His YouTube videos | Same |
| Beats (`public/audio/`) | Files he sent: `Rolling A Dice BEAT .wav`, `Mysterious.wav` | Encoded to 128 kbps MP3 |
